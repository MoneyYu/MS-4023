# Copilot Notebook vs Copilot Pages｜完整比較與使用指南

***

## 一、產品定位

|                | **Copilot Notebook**               | **Copilot Pages**                |
| -------------- | ---------------------------------- | -------------------------------- |
| **一句話定義** | 個人的「Prompt 實驗室」            | 團隊的「AI 共編文件」            |
| **類比**       | 像一張可以反覆擦寫的白板           | 像一份多人共編的 Google Doc      |
| **核心理念**   | 把 Prompt 當「程式碼」一樣迭代優化 | 把 AI 產出當「文件」一樣協作編輯 |

***

## 二、介面與操作方式

### Copilot Notebook

*   **雙欄介面**：左側是 Prompt 編輯區，右側是 AI 回應區
*   Prompt 區支援**長篇輸入**（最高約 18,000 字元），可以寫非常結構化的指令
*   修改左側 Prompt 後，點擊「送出」即可**重新產生**右側回應
*   **沒有對話歷史**——每次執行都是獨立的、乾淨的
*   操作入口：Microsoft 365 Copilot → 切換到「Notebook」分頁

### Copilot Pages

*   **文件式介面**：類似 Word / OneNote 的單欄編輯器
*   從 Copilot Chat 的回應中，點擊**「在 Pages 中編輯」**進入
*   進入後可以：
    *   直接手動編輯文字
    *   選取段落 → 請 Copilot 改寫、擴充、縮短
    *   透過 Chat 側邊欄繼續對 Page 內容下指令
*   **支援多人協作**——可透過連結邀請他人共同編輯
*   操作入口：Copilot Chat 回應 →「在 Pages 中編輯」，或從 Pages 清單開啟

## 三、核心功能比較

| 功能維度          | **Copilot Notebook**             | **Copilot Pages**                     |
| ----------------- | -------------------------------- | ------------------------------------- |
| **Prompt 長度**   | ✅ 超長（~18,000 字元）           | ⚠️ 受限於 Chat 輸入框                  |
| **結構化 Prompt** | ✅ 支援 Markdown 標題、條列、分段 | ❌ 只能在 Chat 中逐句下指令            |
| **迭代修改**      | ✅ 直接改 Prompt 重跑，不留歷史   | ✅ 在文件上持續追加/改寫               |
| **對話歷史影響**  | ❌ 每次都是乾淨執行               | ⚠️ 受前文脈絡影響                      |
| **多人協作**      | ❌ 僅限個人                       | ✅ 可分享連結、即時共編                |
| **產出格式**      | 純文字 / Markdown                | 富文字文件（可含標題、表格等）        |
| **持久保存**      | ✅ Prompt 和回應都會保存          | ✅ 文件持久保存於 M365                 |
| **版本管理**      | ⚠️ 手動管理（覆蓋式）             | ⚠️ 手動管理                            |
| **匯出方式**      | 複製貼上到其他工具               | 直接在 Pages 中編輯，或複製到其他工具 |
| **Web 搜尋**      | ✅ 支援即時 Web 搜尋              | ✅ 支援（透過 Chat 指令）              |

## 四、適用場景對照

### 適合用 Notebook 的情境

| 場景                       | 為什麼選 Notebook                                 |
| -------------------------- | ------------------------------------------------- |
| 🔄 **反覆調校 Prompt**      | 可以直接修改重跑，不會被對話歷史干擾              |
| 📋 **建立分析範本**         | 寫好一個結構化 Prompt，未來只改關鍵字就能重複使用 |
| 📊 **每週/每月固定報告**    | 同一個 Prompt 範本，定期跑出最新結果              |
| 🧪 **測試不同 Prompt 寫法** | 像做實驗一樣，改一個變數、觀察結果差異            |
| 📝 **長篇複雜指令**         | 需要詳細的角色設定、格式要求、多段分析            |

### 適合用 Pages 的情境

| 場景                   | 為什麼選 Pages                              |
| ---------------------- | ------------------------------------------- |
| 👥 **團隊共同編輯**     | 多人可以同時在同一份文件上工作              |
| 📄 **產出正式文件**     | AI 產出後需要人工潤飾、補充、定稿           |
| 🔗 **持續累積內容**     | 不是一次性分析，而是持續追加章節            |
| 💬 **從 Chat 延伸**     | 聊到一半覺得「這段值得保留」，一鍵轉成 Page |
| 📢 **分享給利害關係人** | 需要把結果分享給主管或跨部門同事            |

## 五、以光寶科技為例的實際工作流程

### 場景：準備「AI 伺服器電源市場月報」

```
步驟 1 → Chat（發想）
    「光寶科技在 AI 伺服器電源市場的最新動態是什麼？」
    → 快速取得方向感

步驟 2 → Notebook（深度分析）
    貼入結構化 Prompt：
    - 角色：產業分析師
    - 範圍：過去 1 個月
    - 架構：市場概覽 / 競品動態 / 策略建議
    - 格式：繁體中文、商務語氣、條列式
    → 反覆調校到滿意為止

步驟 3 → Pages（團隊協作）
    把 Notebook 的最終產出複製到 Pages
    → 分享給策略團隊
    → 團隊成員補充內部數據、修正觀點
    → 最終定稿
```

### 三工具在這個流程中的角色

```
┌─────────┐     ┌──────────┐     ┌─────────┐
│  Chat   │ ──→ │ Notebook │ ──→ │  Pages  │
│ 快速問答 │     │ 深度分析  │     │ 團隊協作 │
│ 靈感發想 │     │ 範本迭代  │     │ 共編定稿 │
└─────────┘     └──────────┘     └─────────┘
   探索              打磨             產出
  （1 分鐘）        （5-10 分鐘）     （持續）
```

## 六、常見問題

### Q1：Notebook 的回應可以直接轉成 Page 嗎？

目前不能一鍵轉換。需要**複製 Notebook 回應 → 貼到 Chat → 再從 Chat 轉成 Page**，或直接複製到已有的 Page 中。

### Q2：Pages 可以像 Notebook 一樣「重跑」嗎？

不行。Pages 是**累積式**的——你只能在既有內容上追加或修改，不能像 Notebook 一樣「清掉重來」。如果需要完全重新產生，建議回到 Notebook。

### Q3：哪個工具的 AI 回應品質比較好？

**Notebook 通常能產出更高品質的回應**，因為：
*   Prompt 可以寫得更長、更結構化
*   不受對話歷史干擾
*   每次都是乾淨的執行環境

### Q4：可以同時使用兩個工具嗎？

可以，而且**建議搭配使用**。實際工作中最有效的方式是：
*   用 Notebook 把 Prompt 調到最好
*   把結果帶到 Pages 給團隊協作

## 七、總結

|              | **Chat** | **Notebook**     | **Pages**        |
| ------------ | -------- | ---------------- | ---------------- |
| **速度**     | ⚡ 最快   | 🔧 中等           | 📝 持續           |
| **深度**     | 淺層     | 深層             | 深層 + 人工補充  |
| **協作**     | ❌        | ❌                | ✅                |
| **可重複性** | ❌        | ✅                | ⚠️                |
| **適合誰**   | 所有人   | 需要反覆分析的人 | 需要團隊產出的人 |

### 🎯 選擇原則

> *   **快速問一下** → 用 **Chat**
> *   **反覆調校、建立範本** → 用 **Notebook**
> *   **團隊共編、產出定稿** → 用 **Pages**
> *   **完整工作流** → **Chat → Notebook → Pages**

### 💡 給光寶科技學員的一句話

> **不要只會用 Chat。**  
> 當你的需求從「問一個問題」變成「做一份分析」，  
> 就是該打開 Notebook 的時候。  
> 當你的分析需要「給別人看」，  
> 就是該轉到 Pages 的時候。
