**明門實業股份有限公司研究 DEMO** 全流程 **V0 → V5.5** 的每個版本的 Prompt 都寫成「可直接複製使用」的完整版本，並且在有多個子步驟的地方，為你加上詳細說明與指令，在課堂或工作坊中逐步演示 Prompt Engineering 的威力。  

---

## **V0：直覺版（對照組）**
**目標**：作為對照組，不做任何優化，讓觀眾看到「隨便問」的結果。  
**Prompt：**
```
請幫我整理明門實業股份有限公司的公司介紹與重點資訊。
```
**重點缺陷**：
- 沒有提供上下文
- 沒有輸出結構
- 沒有資料來源要求

---

## **V1：角色與目標導向**
**目標**：加入使用者角色與明確目標，讓模型不再亂猜需求。  
**Prompt：**
```
你是大學商管系學生，要完成一份關於【明門實業股份有限公司】的入門研究作業。
請用不超過1500字的摘要，介紹該公司是做什麼的，以及為何值得關注。
語言使用繁體中文，避免使用行話，讓初學者也能理解。
```
**改進點**：
- 有角色設定（學生）
- 有目的（入門研究摘要）
- 有字數限制與語言要求

---

## **V2：結構與來源 + 四大要點**
**目標**：引入「提供上下文、描述目標、定義源、設置期望」四大要點，讓模型產出可驗證的結構化內容。  
**Prompt：**
```
提供上下文：
你是一位大學商管系學生，正在為「企業研究方法」課堂完成一份關於【明門實業股份有限公司】的入門研究報告，將用於課堂小組簡報。聽眾是對該公司完全陌生的同學與老師。

描述目標：
請生成一份結構化的公司研究簡報稿，包含：
- 公司速覽（100-150字）
- 主要產品/服務（3-5項）
- 商業模式與主要客戶（條列3點內）
- 近三年重點事件（3-5則，每則附來源網址與年份）
- 風險與不確定性（3點內）
- 參考資料（來源名稱 + URL）

定義源：
僅使用公開可驗證的資訊來源（公司官網、政府公開資訊、主流媒體）。
每則事實必須附來源名稱、可點擊網址與年份。
若找不到資訊，請標示「資料缺口」並建議下一步查詢管道。

設置期望：
以條理分明的小標題呈現，保持中立專業的語氣。
最後附「資料完整度與新鮮度自評」（來源齊全度、資料時效性、缺口比例）。
```

## **V3：流程分階段 + 不確定性標註**
**目標**：拆成多步驟互動，先對齊大綱再出內容，並標記資料可信度。  
**Prompt：**
```
提供上下文：
你是一位大學商管系學生，正在為「企業研究方法」課堂製作一份關於【明門實業股份有限公司】的入門研究報告。這份報告將用於課堂小組簡報，聽眾是對該公司完全陌生的同學與老師。

描述目標：
請最終產出一份結構化的公司研究內容，包含：
- 公司速覽（100-150字）
- 主要產品/服務（3-5項）
- 商業模式與主要客戶（條列3點內）
- 近三年重點事件（3-5則，每則附來源名稱、可點擊網址與年份）
- 風險與不確定性（3點內）
- 參考資料（來源名稱 + URL）

定義源：
僅使用公開可驗證的資訊來源（公司官網、政府公開資訊平台、主流新聞媒體）。
若找不到資料，請標示「資料缺口」並提供下一步可查詢管道（如：公司年報、法說會簡報、政府公告）。

設置期望：
保持中立、專業語氣，避免行話，使沒有背景知識的聽眾也能理解。
最終稿需條理分明、小標清晰，且在每則事實後附來源名稱、URL 與年份。

---

步驟一：
請先輸出「大綱草案」——列出所有小節標題，並在每節後附一句簡述，讓我確認範圍與順序。

步驟二：
等待我輸入「OK」後，再依照確認過的大綱逐節生成完整內容。

額外規則：
- 每則事實附來源名稱、可點擊網址與年份。
- 若資料僅有單一來源或時間過舊 → 標示「低信心」並說明原因。
- 無資料時 → 標示「資料缺口」並提供可行的下一步查詢建議（例如：公司年報、政府資料庫）。

語言要求：
- 全文繁體中文
- 避免行話，面向沒有背景知識的聽眾
```

## **V3.5：Few-shot Learning 範例**
**目標**：用範例教模型格式與語氣，減少跑偏。  
**Prompt：**
```
以下為範例輸入與輸出：

【範例輸入】
請生成「台積電」的入門研究卡片，包含：
公司速覽、主要產品/服務（3-5項）、近3年事件（來源+年份）、風險與資料缺口。

【範例輸出】
公司速覽：
台灣積體電路製造股份有限公司（TSMC）為全球半導體代工龍頭...
主要產品/服務：
- 半導體製造（先進製程至成熟製程）
- 封裝與測試服務
...
近3年事件：
1. 2022年 建設美國亞利桑那廠（來源：路透社, 2022）
...
風險與資料缺口：
- 高度依賴全球供應鏈
- 未公開特定研發細節

請套用完全相同的格式與語氣，生成「明門實業股份有限公司」的入門研究卡片。
```

## **V4：可比性模板 + 品質量表**
**目標**：建立跨公司比較模板，並加上品質檢查。Specifying the output structure 
**Prompt：**
```
請建立一個 Markdown 表格，列名固定為：
公司名稱｜產業類別｜主要產品/服務｜商業模式｜
客戶與通路｜近3年事件（來源+年份）｜風險｜
核心指標（附定義）｜資料缺口｜來源清單

完成表格後，請依下列品質量表為結果打分（0-2分/項）：
- 來源可驗證度
- 資料新鮮度
- 完整性（所有欄位皆有內容或標示缺口）
- 客觀性（避免推測）
```

## **V4.5：Chain of Thought Prompting**
**目標**：要求模型先輸出推理步驟，方便檢查邏輯與資料可信度。  
**Prompt：**
```
步驟一：
請先用條列方式輸出你將如何蒐集、篩選、整合「明門實業股份有限公司」資料的推理步驟，並在每步後附上資料可驗證性評估（高 / 中 / 低）。

步驟二：
等待我輸入「OK」後，依推理步驟生成正式的研究卡片。
```

---

## **V5：限制覺知 + 研究計畫備援**
**目標**：示範 AI 在資料不足時如何提供替代方案與誠實輸出。  
**Prompt：**
```
規則：
- 無來源則標示「未知」，不得推測。
- 若無法即時查詢，請輸出「研究計畫」，列出：
  - 需查詢的文件或資料庫
  - 搜尋關鍵字
  - 預估時間
  - 優先順序
- 最後附「限制說明」與可能風險。

請依此規則生成「明門實業股份有限公司」的入門研究摘要。
```

---

## **V5.5：Specifying the Output Structure**
**目標**：嚴格定義輸出欄位、順序與限制，確保一致性。  
**Prompt：**
```
請以 Markdown 表格輸出，欄位與順序如下：
1. 公司名稱（全名）
2. 成立年份（YYYY）
3. 產業類別（3-5字）
4. 公司速覽（100字內）
5. 主要產品/服務（3-5項，每項不超過12字）
6. 近3年事件（每則附來源+年份）
7. 風險（3項，每項不超過15字）
8. 資料缺口（條列）
9. 參考資料（來源名稱+URL）

規則：
- 無資料則輸出「未知」
- 全文繁體中文
- 不加額外評論或分析
```
